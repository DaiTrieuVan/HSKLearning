# Implementation Plan — HTT-05-CN-006: Tạo bài tập từ câu hỏi

## 1. Nguồn và phạm vi
- **Story:** HTT-05-CN-006 — Tạo bài tập từ câu hỏi (Chọn câu hỏi từ ngân hàng, đặt điểm từng câu, đóng gói thành bài tập hoàn chỉnh).
- **Vai trò:** Giáo viên (Teacher / Admin).
- **Mục tiêu:** Cho phép giáo viên đặt tên bài tập, chọn câu hỏi từ ngân hàng cá nhân, gán điểm số từng câu, sắp xếp thứ tự và lưu bài ở trạng thái nháp (DRAFT) hoặc sẵn sàng giao (READY).
- **Quy tắc nghiệp vụ:**
  - `QTN-09`: Bài tập chỉ giao khi hợp lệ (ít nhất 1 câu hỏi và hạn nộp sau thời điểm giao). Bài tập 0 câu hỏi chỉ được phép lưu ở dạng nháp (`DRAFT`), không được chuyển sang trạng thái sẵn sàng giao (`READY`).
  - `QTN-14`: Nội dung đã sử dụng chỉ được ẩn. Khi câu hỏi được đưa vào bài tập, câu hỏi đó được đánh dấu đã sử dụng để bảo vệ tính toàn vẹn dữ liệu.
  - `QTN-19`: Nội dung riêng thuộc về giáo viên tạo ra. Giáo viên chỉ được xem và chọn câu hỏi do chính mình tạo ra (`owner_id`). Tuyệt đối không cho phép đưa câu hỏi của giáo viên khác vào bài tập của mình (HTTP 403 Forbidden).
- **Acceptance Criteria & Test Cases:**
  - `TC-01`: Giáo viên nhập tên bài, chọn câu hỏi từ ngân hàng và đặt điểm từng câu -> Bài tập được lưu (DRAFT/READY), tổng điểm tự động tính bằng tổng điểm các câu.
  - `TC-02`: Đổi thứ tự câu hoặc bỏ bớt câu rồi lưu -> Bài tập được lưu theo thứ tự và danh sách mới.
  - `TC-03`: Bỏ trống tên bài tập -> Báo lỗi tên bài là bắt buộc (HTTP 400).
  - `TC-04`: Điểm của câu bằng 0, âm hoặc không hợp lệ -> Báo lỗi điểm phải lớn hơn 0 (HTTP 400).
  - `TC-05`: Bài tập chưa có câu hỏi nào (0 câu) -> Chỉ cho phép lưu dạng nháp (`DRAFT`), chặn chuyển sang sẵn sàng giao (`READY`).
  - `TC-06`: Chọn cùng một câu hỏi hai lần trong bài -> Báo lỗi trùng lặp câu hỏi (HTTP 400).
  - `TC-07`: Câu hỏi thuộc giáo viên khác -> Hệ thống từ chối (HTTP 403 Forbidden).
- **Phụ thuộc:** HTT-05-CN-001, HTT-05-CN-005.

## 3. Kiến trúc Backend & Data Contract

### A. Database Schema (`V11__create_exercise_tables.sql`)
```sql
CREATE TABLE IF NOT EXISTS exercises (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    owner_id BIGINT NOT NULL,
    title VARCHAR(255) NOT NULL,
    description TEXT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'DRAFT',
    total_points DECIMAL(6,2) NOT NULL DEFAULT 0.00,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_exercises_owner FOREIGN KEY (owner_id) REFERENCES users(id) ON DELETE CASCADE,
    INDEX idx_exercises_owner (owner_id),
    INDEX idx_exercises_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;

CREATE TABLE IF NOT EXISTS exercise_questions (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    exercise_id BIGINT NOT NULL,
    question_id BIGINT NOT NULL,
    points DECIMAL(6,2) NOT NULL DEFAULT 1.00,
    sort_order INT NOT NULL DEFAULT 1,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT fk_eq_exercise FOREIGN KEY (exercise_id) REFERENCES exercises(id) ON DELETE CASCADE,
    CONSTRAINT fk_eq_question FOREIGN KEY (question_id) REFERENCES questions(id) ON DELETE CASCADE,
    UNIQUE KEY uk_exercise_question (exercise_id, question_id),
    INDEX idx_eq_exercise (exercise_id),
    INDEX idx_eq_question (question_id)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

### B. RESTful API Contracts
- `POST /api/exercises`: Tạo bài tập mới
- `GET /api/exercises/my`: Lấy danh sách bài tập của giáo viên đăng nhập
- `GET /api/exercises/{id}`: Xem chi tiết bài tập kèm danh sách câu hỏi
