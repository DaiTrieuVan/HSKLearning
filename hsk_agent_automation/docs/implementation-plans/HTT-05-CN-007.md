# Implementation Plan — HTT-05-CN-007: Sao chép bài tập

## 1. Nguồn và phạm vi
- **Story:** HTT-05-CN-007 — Sao chép bài tập (Copy / Clone Exercise).
- **Vai trò:** Giáo viên (Teacher / Admin).
- **Mục tiêu:** Cho phép giáo viên sao chép một bài tập có sẵn thành một bài tập mới độc lập ở trạng thái nháp (`DRAFT`), sao chép toàn bộ danh sách câu hỏi, điểm số và thứ tự sắp xếp để tái sử dụng cho lớp khác mà không cần soạn lại từ đầu.
- **Quy tắc nghiệp vụ:**
  - `QTN-19`: Nội dung riêng thuộc về giáo viên tạo ra. Giáo viên chỉ xem, sửa và sao chép bài tập do chính mình tạo ra (`owner_id`). Nghiêm cấm sao chép bài tập của giáo viên khác (HTTP 403 Forbidden).
  - Trạng thái bản sao: Bản sao luôn được tạo ở trạng thái nháp (`DRAFT`), sẵn sàng để giáo viên tùy chỉnh trước khi giao cho lớp.
  - Tính độc lập của bản sao: Bản sao hoàn toàn độc lập với bài gốc. Các chỉnh sửa trên bản sao (sửa điểm, xóa/thêm câu hỏi, đổi tên) không ảnh hưởng tới bài gốc hoặc các bài đã giao trước đó (`TC-02`).
  - Dữ liệu độc lập: Bản sao không mang theo bất kỳ dữ liệu nộp bài, điểm số học viên hay hạn nộp nào của bài gốc (`TC-03`).
- **Acceptance Criteria & Test Cases:**
  - `TC-01`: Sao chép bài tập thành công -> Tạo bản sao ở trạng thái `DRAFT` với đầy đủ câu hỏi, điểm từng câu và thứ tự sắp xếp; bài gốc không thay đổi.
  - `TC-02`: Độc lập bản sao -> Khi sửa đổi bản sao, bài gốc và các bài đã giao không bị ảnh hưởng.
  - `TC-03`: Sao chép bài đã giao -> Bản sao được tạo nhưng không mang theo bài nộp/hạn nộp của bài gốc.
  - `TC-04`: Thử sao chép bài tập của giáo viên khác -> Hệ thống từ chối HTTP 403 Forbidden (`ACCESS_DENIED_EXERCISE`).
- **Phụ thuộc:** HTT-05-CN-006.

## 3. Kiến trúc Backend & Data Contract

### A. API Endpoints
- `POST /api/exercises/{id}/copy`
  - Quyền truy cập: `ROLE_TEACHER`, `ROLE_ADMIN`
  - URL Param: `id` (ID bài tập gốc cần sao chép)
  - Request Body (Tùy chọn):
    ```json
    {
      "newTitle": "Kiểm tra bài 1 (Bản sao cho Lớp HSK2)" // Nếu bỏ trống hoặc null, mặc định là "[Tên bài gốc] (Bản sao)"
    }
    ```
  - Response Body: `ExerciseResponse` (HTTP 201 Created)
    ```json
    {
      "id": 12,
      "title": "Kiểm tra bài 1 (Bản sao)",
      "description": "Mô tả bài tập cũ...",
      "status": "DRAFT",
      "totalPoints": 10.0,
      "createdAt": "2026-10-16T15:50:00Z",
      "updatedAt": "2026-10-16T15:50:00Z",
      "questions": [
        {
          "id": 101,
          "questionId": 5,
          "content": "Nội dung câu...",
          "type": "SINGLE_CHOICE",
          "hskLevel": "HSK1",
          "points": 2.0,
          "sortOrder": 1
        }
      ]
    }
    ```

### B. Business Logic ([ExerciseService.java](file:///d:/Test%20OpenCode/WebHocTiengTrung/HSK/backend/src/main/java/com/example/hsk/exercise/ExerciseService.java))
1. Tìm bài tập nguồn theo `id`:
   - Nếu không tìm thấy: ném `ApiException(ApiErrorCode.EXERCISE_NOT_FOUND)` (HTTP 404).
2. Kiểm tra quyền sở hữu (`QTN-19`):
   - Nếu `sourceExercise.getTeacher().getId() != currentTeacherId`: ném `ApiException(ApiErrorCode.ACCESS_DENIED_EXERCISE)` (HTTP 403).
3. Xác định tiêu đề bài tập mới:
   - Nếu `request != null && StringUtils.hasText(request.getNewTitle())`: dùng `request.getNewTitle().trim()`.
   - Nếu không có: tự động sinh `sourceExercise.getTitle() + " (Bản sao)"`.
4. Tạo và lưu thực thể `ExerciseEntity` mới:
   - `teacher`: Giáo viên đang đăng nhập.
   - `title`: Tên mới đã xác định.
   - `description`: Sao chép từ bài nguồn.
   - `status`: Luôn đặt là `ExerciseStatus.DRAFT`.
   - `totalPoints`: Sao chép từ `sourceExercise.getTotalPoints()`.
5. Sao chép danh sách câu hỏi:
   - Đọc danh sách câu hỏi gốc từ `exerciseQuestionRepository.findByExerciseIdOrderBySortOrderAsc(sourceExercise.getId())`.
   - Với mỗi câu hỏi, tạo mới `ExerciseQuestionEntity` với `exercise = newExercise`, `question = item.getQuestion()`, `points = item.getPoints()`, `sortOrder = item.getSortOrder()`.
   - Lưu toàn bộ vào `exercise_questions`.
6. Trả về `ExerciseResponse` đầy đủ thông tin bài tập mới tạo.
