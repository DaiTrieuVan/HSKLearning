# Implementation Plan — HTT-05-CN-008: Chỉnh sửa bài tập

## 1. Nguồn và phạm vi
- **Story:** HTT-05-CN-008 — Chỉnh sửa bài tập (Update Exercise).
- **Vai trò:** Giáo viên (Teacher / Admin).
- **Mục tiêu:** Cho phép giáo viên cập nhật tiêu đề, mô tả, trạng thái (DRAFT / READY), danh sách câu hỏi, số điểm từng câu và thứ tự sắp xếp của bài tập có sẵn để hoàn thiện bài trước khi giao cho học sinh.
- **Quy tắc nghiệp vụ:**
  - `QTN-10`: Nội dung lần giao bài được cố định. Việc sửa bài tập gốc chỉ cập nhật nội dung bài tập trong thư viện của giáo viên, không làm ảnh hưởng đến các lần giao bài đã tạo trước đó hoặc học sinh đang làm bài.
  - `QTN-19`: Nội dung riêng thuộc về giáo viên tạo ra. Giáo viên chỉ được xem và sửa bài tập do chính mình tạo ra (`owner_id`). Nghiêm cấm sửa bài tập của giáo viên khác (HTTP 403 Forbidden).
  - `QTN-09`: Bài tập chuyển sang trạng thái sẵn sàng giao (`READY`) bắt buộc phải có ít nhất 1 câu hỏi. Bài tập 0 câu hỏi chỉ được lưu ở trạng thái nháp (`DRAFT`).
  - `QTN-14`: Câu hỏi đưa vào bài tập được đánh dấu đã sử dụng để bảo vệ tính toàn vẹn dữ liệu.
  - Validation:
    - Tiêu đề bài tập không được để trống (`EXERCISE_TITLE_BLANK` - HTTP 400).
    - Điểm số của từng câu hỏi phải lớn hơn 0 (`EXERCISE_QUESTION_POINTS_INVALID` - HTTP 400).
    - Không được chọn trùng câu hỏi trong cùng một bài tập (`EXERCISE_DUPLICATE_QUESTIONS` - HTTP 400).
    - Không được thêm câu hỏi thuộc sở hữu của giáo viên khác (`ACCESS_DENIED_QUESTION` - HTTP 403).
- **Acceptance Criteria & Test Cases:**
  - `TC-01`: Sửa bài tập ở trạng thái nháp (sửa tên, thứ tự câu, điểm từng câu) -> Bài tập được cập nhật thành công, tổng điểm được tính lại chuẩn xác.
  - `TC-02`: Sửa bài tập đã giao -> Bài tập gốc được cập nhật dữ liệu mới; các lần giao bài đã tạo giữ nguyên dữ liệu đã chụp.
  - `TC-03`: Giao lần mới từ bài tập đã sửa -> Lần giao mới dùng nội dung đã cập nhật, lần giao cũ không bị ảnh hưởng.
  - `TC-04`: Xóa trống tên bài tập khi sửa -> Hệ thống báo lỗi tiêu đề là bắt buộc (HTTP 400 `EXERCISE_TITLE_BLANK`).
  - `TC-05`: Thử sửa bài tập của giáo viên khác -> Hệ thống từ chối HTTP 403 Forbidden (`ACCESS_DENIED_EXERCISE`).
  - `TC-06`: Bài tập 0 câu hỏi cập nhật sang trạng thái READY -> Hệ thống báo lỗi (HTTP 400 `EXERCISE_READY_REQUIRES_QUESTIONS`).
- **Phụ thuộc:** HTT-05-CN-006.

## 3. Kiến trúc Backend & Data Contract

### A. Endpoint API
- `PUT /api/exercises/{id}`
  - Quyền truy cập: `ROLE_TEACHER`, `ROLE_ADMIN`
  - URL Param: `id` (ID bài tập cần chỉnh sửa)
  - Request Body:
    ```json
    {
      "title": "Kiểm tra 15 phút bài 1 (Đã cập nhật)",
      "description": "Hướng dẫn làm bài mới...",
      "status": "READY", // DRAFT hoặc READY
      "questions": [
        {
          "questionId": 10,
          "points": 3.0,
          "sortOrder": 1
        },
        {
          "questionId": 12,
          "points": 7.0,
          "sortOrder": 2
        }
      ]
    }
    ```
  - Response Body: `ExerciseResponse` (HTTP 200 OK)

### B. DTOs
- `UpdateExerciseRequest`: record DTO tương đương với `CreateExerciseRequest`:
  ```java
  public record UpdateExerciseRequest(
      @NotBlank(message = "Tên bài tập không được để trống")
      String title,
      String description,
      ExerciseStatus status,
      List<CreateExerciseQuestionItem> questions
  ) {}
  ```

### C. Business Logic ([ExerciseService.java](file:///d:/Test%20OpenCode/WebHocTiengTrung/HSK/backend/src/main/java/com/hsk/exercise/service/ExerciseService.java))
1. Kiểm tra quyền sở hữu (`QTN-19`):
   - Tìm bài tập theo `id`. Nếu không tồn tại: ném `EXERCISE_NOT_FOUND` (404).
   - Nếu `exercise.getOwnerId() != currentTeacherId`: ném `ACCESS_DENIED_EXERCISE` (403).
2. Kiểm tra validation:
   - Nếu `request.title()` để trống -> Ném `EXERCISE_TITLE_BLANK` (400).
   - Kiểm tra `QTN-09`: nếu `status == READY` và danh sách câu hỏi rỗng/null -> Ném `EXERCISE_READY_REQUIRES_QUESTIONS` (400).
   - Kiểm tra trùng lặp `questionId` trong danh sách -> Ném `EXERCISE_DUPLICATE_QUESTIONS` (400).
   - Kiểm tra điểm từng câu `points <= 0` -> Ném `EXERCISE_QUESTION_POINTS_INVALID` (400).
   - Kiểm tra từng câu hỏi có tồn tại và thuộc quyền sở hữu của giáo viên đăng nhập (`QTN-19`) -> Nếu thuộc giáo viên khác, ném `ACCESS_DENIED_QUESTION` (403).
3. Cập nhật dữ liệu:
   - Cập nhật `title`, `description`, `status`.
   - Xóa các liên kết câu hỏi cũ trong `exercise_questions` thông qua `exerciseQuestionRepository.deleteByExercise_Id(exerciseId)`.
   - Tạo danh sách `ExerciseQuestionEntity` mới, gán `points`, `sortOrder`, đánh dấu `markQuestionAsUsedInExercise` (`QTN-14`).
   - Tính toán lại `totalPoints` = tổng điểm các câu hỏi thành phần.
   - Lưu và trả về `ExerciseResponse`.
