  - `HTT-06-CN-005`: Xem kết quả làm bài.
- Việc tạo bảng `assignment_submissions` là hoàn toàn độc lập, cần thiết và tuân thủ chặt chẽ nguyên tắc chỉ tạo bảng khi phát sinh thực thể nghiệp vụ mới.

### Migration đề xuất: `V13__create_assignment_submission_tables.sql`
```sql
CREATE TABLE IF NOT EXISTS assignment_submissions (
    id BIGINT AUTO_INCREMENT PRIMARY KEY,
    assignment_id BIGINT NOT NULL,
    student_id BIGINT NOT NULL,
    status VARCHAR(50) NOT NULL DEFAULT 'IN_PROGRESS',
    attempt_number INT NOT NULL DEFAULT 1,
    score DECIMAL(6,2) NULL,
    submitted_at TIMESTAMP NULL,
    started_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    answers_data LONGTEXT NULL,
    created_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP NOT NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
    CONSTRAINT fk_submissions_assignment FOREIGN KEY (assignment_id) REFERENCES assignments(id) ON DELETE CASCADE,
    CONSTRAINT fk_submissions_student FOREIGN KEY (student_id) REFERENCES users(id) ON DELETE CASCADE,
    CONSTRAINT uq_assignment_student_attempt UNIQUE (assignment_id, student_id, attempt_number),
    INDEX idx_submissions_assignment (assignment_id),
    INDEX idx_submissions_student (student_id),
    INDEX idx_submissions_status (status)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci;
```

## 3. Kiến trúc Backend & Chiến lược Tránh N+1 (Senior Backend Mode)

### A. Quy tắc xác định trạng thái bài tập của học sinh (StudentAssignmentStatus)
Hệ thống tính toán trạng thái cá nhân hóa cho từng bài tập dựa trên thời gian máy chủ (`Instant.now()`) và bản ghi nộp bài mới nhất của học sinh:
1. **`UPCOMING` (Chưa mở):** `now < assignment.startTime` -> Học sinh thấy bài nhưng nút làm bài vô hiệu hóa (`canStart = false`), không để lộ nội dung câu hỏi.
2. **`SUBMITTED` (Đã nộp):** Học sinh có bản ghi nộp bài với trạng thái `SUBMITTED`, `AUTO_SUBMITTED`, hoặc `GRADED` -> `canStart = false`, hiển thị `submittedAt` và `score`.
3. **`IN_PROGRESS` (Đang làm dở):** Học sinh có bản ghi `IN_PROGRESS` và `now <= assignment.dueTime` -> `canStart = true`.
4. **`OVERDUE` (Quá hạn chưa nộp):** `now > assignment.dueTime` và học sinh chưa có bài nộp hoàn tất -> `canStart = false`.
5. **`NOT_STARTED` (Chưa làm):** `now >= assignment.startTime && now <= assignment.dueTime` và học sinh chưa từng bắt đầu -> `canStart = true`.

### B. Tránh N+1 Query:
- Không lặp qua từng `assignment` rồi gọi DB tìm submission.
- Thay vào đó: Batch fetch tất cả submission của học sinh trong lớp bằng một query đơn lẻ:
  ```java
  List<AssignmentSubmissionEntity> submissions = submissionRepository.findByAssignment_Classroom_IdAndStudent_Id(classId, studentId);
  Map<Long, AssignmentSubmissionEntity> submissionMap = submissions.stream()
      .collect(Collectors.toMap(s -> s.getAssignment().getId(), s -> s, (s1, s2) -> s1.getAttemptNumber() > s2.getAttemptNumber() ? s1 : s2));
  ```
- Duyệt qua danh sách `assignments` và lấy O(1) từ `submissionMap`.

### C. DTOs và Endpoint Contracts:
- Enum: `StudentAssignmentStatus` (`UPCOMING`, `NOT_STARTED`, `IN_PROGRESS`, `SUBMITTED`, `OVERDUE`)
- Response DTO: `StudentAssignmentResponse`
  ```java
  public record StudentAssignmentResponse(
      Long id,
      Long exerciseId,
      Long classId,
      String className,
      String title,
      String description,
      Instant startTime,
      Instant dueTime,
      BigDecimal totalPoints,
      int questionCount,
      StudentAssignmentStatus studentStatus,
      boolean canStart,
      Long submissionId,
      Instant submittedAt,
      BigDecimal score
  ) {}
  ```
- Endpoints:
  1. `GET /api/assignments/classes/{classId}/student`: Lấy danh sách bài tập của lớp với trạng thái học sinh.
     - Kiểm tra học sinh là thành viên `ACTIVE` của lớp (`QTN-18`). Nếu không -> 403 Forbidden.
     - Chỉ trả về dữ liệu của chính học sinh đăng nhập (`QTN-02`).
  2. `GET /api/assignments/{id}/student`: Xem chi tiết bài tập dành cho học sinh.
     - Kiểm tra học sinh có thuộc lớp của bài tập đó không (`QTN-18`). Nếu không -> 403 Forbidden (`TC-05`).
     - Nếu `startTime > now()` -> Trả về thông tin tổng quan, ẩn câu hỏi (`TC-03`).
