## 1. 🎯 Tổng quan Kiến trúc (Architecture Summary)
Cung cấp cho Giáo viên cái nhìn tổng quan toàn diện về tiến độ và kết quả làm bài của lớp học đối với một bài tập được giao:
- Thống kê tổng số học sinh, số em đã nộp (`SUBMITTED`), tự nộp (`AUTO_SUBMITTED`), đang làm (`IN_PROGRESS`), và chưa làm (`NOT_STARTED`).
- Hiển thị danh sách học sinh kèm điểm số, thời gian nộp và lượt làm bài.
- Cho phép giáo viên bấm xem chi tiết từng bài làm (đáp án học sinh chọn, đúng/sai, đáp án chuẩn, lời giải).
- Đảm bảo quy tắc `QTN-01`: Chỉ giáo viên phụ trách lớp mới được xem dữ liệu, từ chối với `HTTP 403 Forbidden` nếu truy cập bài thuộc lớp khác.
- UI/UX tuân thủ GEMINI.md: 100% SVG Vector Icons (Lucide React), không dùng Modal (hiển thị danh sách và chi tiết inline hoặc subpage).

## 2. 🗄️ Hợp đồng API & DTOs

### `StudentSubmissionSummaryDto.java`
```java
public record StudentSubmissionSummaryDto(
    Long studentId,
    String studentName,
    String studentEmail,
    String status,                // NOT_STARTED, IN_PROGRESS, SUBMITTED, AUTO_SUBMITTED
    BigDecimal score,             // Điểm gốc
    BigDecimal adjustedScore,     // Điểm sau điều chỉnh nếu có
    BigDecimal effectiveScore,    // Điểm hiển thị cao nhất
    Integer attemptNumber,
    Instant submittedAt,
    Instant extendedDueTime,      // Hạn riêng nếu có
    Integer allowedAttempts       // Số lượt được phép làm nếu có gia hạn
) {}
```

### `AssignmentSubmissionsOverviewResponse.java`
```java
public record AssignmentSubmissionsOverviewResponse(
    Long assignmentId,
    String assignmentTitle,
    BigDecimal totalPoints,
    Instant dueTime,
    int totalStudents,
    int submittedCount,
    int inProgressCount,
    int notStartedCount,
    List<StudentSubmissionSummaryDto> students

```

### Endpoint
`GET /api/assignments/{id}/submissions`: Giáo viên xem toàn bộ danh sách bài nộp của bài tập `{id}`.

## 3. ⚡ Kế hoạch Kiểm thử (Test Cases)
- `TC-01`: Giáo viên mở bài đã giao -> Hiển thị danh sách học sinh kèm trạng thái, điểm, thời điểm nộp.
- `TC-02`: Học sinh đã nộp bài -> Giáo viên mở chi tiết bài nộp -> Hiển thị câu trả lời, đúng/sai, điểm từng câu.
- `TC-03`: Học sinh chưa nộp bài -> Hiển thị trạng thái chưa nộp và chưa có điểm.
- `TC-04`: Chưa có học sinh nào nộp -> Hệ thống báo danh sách chưa có bài nộp (Empty state).
- `TC-05`: Bài thuộc lớp của giáo viên khác -> Hệ thống từ chối và trả về 403 Forbidden (`QTN-01`).
