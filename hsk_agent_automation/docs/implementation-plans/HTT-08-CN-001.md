### 1. BỐI CẢNH & MỤC TIÊU NGHIỆP VỤ

User Story **HTT-08-CN-001** là tính năng cốt lõi giúp học sinh ghi nhớ từ vựng lâu dài thông qua kỹ thuật **Lặp lại ngắt quãng (Spaced Repetition System - SRS)** dựa trên biến thể thuật toán **SuperMemo SM-2**. 

Hệ thống tự động theo dõi lịch ôn của từng học sinh đối với từng từ vựng đã học. Khi đến hạn ôn (`nextReviewAt <= Instant.now()`), từ vựng sẽ xuất hiện trong danh sách ôn của ngày. Học sinh lật thẻ từ và tự đánh giá (Đã nhớ / Chưa nhớ). Dựa trên kết quả, hệ thống tự động giãn cách khoảng thời gian ôn tiếp theo hoặc thiết lập lại nếu học sinh quên.

#### Các Acceptance Criteria & Test Cases:
- **TC-01 (Luồng thành công — Lấy từ đến hạn hôm nay):**
  - Given: Học sinh có các từ vựng đã học đến hạn ôn hôm nay (`nextReviewAt <= now`).
  - When: Học sinh bắt đầu phiên ôn từ vựng.
  - Then: Hệ thống tập hợp danh sách các từ đến hạn vào phiên ôn và hiển thị từng thẻ từ.
- **TC-02 (Luồng thành công — Đánh giá nhớ lần đầu):**
  - Given: Một từ được đánh giá nhớ lần đầu tiên (`repetitionLevel = 0` hoặc mới bắt đầu).
  - When: Học sinh đánh giá "Đã nhớ".
  - Then: Hệ thống đặt `intervalDays = 1` ngày và `nextReviewAt = now + 1 ngày`, `repetitionLevel = 1`.
- **TC-03 (Luồng thành công — Đánh giá nhớ lần 2 và lần 3):**
  - Given: Một từ đã nhớ lần 1, nay nhớ lần 2.
  - When: Học sinh đánh giá "Đã nhớ".
  - Then: Hệ thống đặt `intervalDays = 6` ngày (`repetitionLevel = 2`). Nếu lần 3 tiếp tục nhớ, nhân hệ số `easeFactor = 2.5` thành `15` ngày (`6 * 2.5 = 15`), `repetitionLevel = 3`.
- **TC-04 (Luồng thành công — Đánh giá chưa nhớ / Quên từ):**
  - Given: Một từ đang có khoảng ôn dài (ví dụ 15 ngày, `repetitionLevel >= 1`).
  - When: Học sinh đánh giá "Chưa nhớ".
  - Then: Hệ thống đưa khoảng cách ôn về `1 ngày`, đặt lại `repetitionLevel = 0` (hoặc 1 theo cấu hình SM-2) và hẹn ôn lại vào ngày mai.
- **TC-05 (Sai trạng thái — Từ chưa đến hạn không xuất hiện):**
  - Given: Từ vựng có ngày hẹn ôn trong tương lai (`nextReviewAt > now`).
  - When: Học sinh mở phiên ôn hôm nay.
  - Then: Từ đó không xuất hiện trong lượt ôn hôm nay.
- **TC-06 (Dữ liệu rỗng — Không có từ cần ôn):**
  - Given: Học sinh không có từ nào đến hạn ôn.
  - When: Học sinh mở phiên ôn tập.
  - Then: Hệ thống thông báo hôm nay không có từ cần ôn, không báo lỗi.
- **TC-07 (Bài học bị ẩn):**
  - Given: Từ vựng thuộc bài học đang bị ẩn (`lesson.hidden = true`).
  - When: Hệ thống lập danh sách ôn tập.
  - Then: Từ đó bị loại trừ khỏi phiên ôn tập.
- **TC-08 (Ngoại lệ — Lưu kết quả tức thì khi thoát giữa chừng):**
  - Given: Phiên ôn có 12 thẻ, học sinh ôn được 5 thẻ rồi thoát trình duyệt.
  - When: Học sinh quay lại sau đó.
  - Then: 5 thẻ đã ôn được cập nhật lịch mới (không còn trong danh sách đến hạn hôm nay), 7 thẻ còn lại vẫn giữ nguyên hạn ôn.
- **TC-09 (Bảo mật QTN-02 — Cách ly dữ liệu cá nhân học sinh):**
  - Given: Học sinh A và Học sinh B cùng học một từ vựng.
  - When: Học sinh A ôn từ và đánh giá.
  - Then: Hệ thống chỉ cập nhật lịch ôn và tiến độ của Học sinh A, dữ liệu của Học sinh B không bị ảnh hưởng.

### 2. THIẾT KẾ DỮ LIỆU & KIẾN TRÚC BACKEND (SENIOR BACKEND MODE)

#### A. Tái sử dụng Schema & Bảng hiện có (Zero Migration)
- Tận dụng triệt để bảng `vocab_learning` và thực thể `VocabLearningEntity` đã có sẵn các trường chuẩn SRS:
  - `user_id` & `vocabulary_id` (Composite Key `VocabLearningId`).
  - `repetition_level`: Số lần ghi nhớ liên tiếp.
  - `interval_days`: Khoảng cách ngày đến lần ôn tiếp theo.
  - `ease_factor`: Hệ số giãn cách (mặc định 2.5).
  - `next_review_at`: Thời điểm chính xác đến hạn ôn tiếp theo.
  - `last_result`: `REMEMBERED` hoặc `FORGOTTEN`.
  - `review_count`: Tổng số lượt ôn tập.

#### B. Thuật toán SM-2 SRS Logic trong `VocabLearningEntity`
```java
public void recordSrsReview(FlashcardResult result) {
    this.lastResult = result;
    this.reviewCount = (this.reviewCount != null ? this.reviewCount : 0) + 1;
    
    if (result == FlashcardResult.REMEMBERED) {
        int currentLevel = this.repetitionLevel != null ? this.repetitionLevel : 0;
        if (currentLevel == 0) {
            this.intervalDays = 1;
            this.repetitionLevel = 1;
        } else if (currentLevel == 1) {
            this.intervalDays = 6;
            this.repetitionLevel = 2;
        } else {
            double ef = this.easeFactor != null ? this.easeFactor : 2.5;
            this.intervalDays = (int) Math.round(this.intervalDays * ef);
            this.repetitionLevel = currentLevel + 1;
        }
    } else {
        // Quên từ -> reset chuỗi ghi nhớ về 0, ôn lại sau 1 ngày
        this.repetitionLevel = 0;
        this.intervalDays = 1;
    }
    this.nextReviewAt = Instant.now().plus(this.intervalDays, ChronoUnit.DAYS);
}
```

#### C. Tối ưu Truy vấn & Tránh N+1 Query
- Trong `VocabLearningRepository`, bổ sung truy vấn tối ưu kèm `JOIN FETCH vocabulary v`:
```java
@Query("""
    SELECT vl FROM VocabLearningEntity vl
    JOIN FETCH vl.vocabulary v
    WHERE vl.user.id = :userId
      AND vl.nextReviewAt <= :now
      AND NOT EXISTS (
          SELECT 1 FROM LessonVocabularyEntity lv
          JOIN lv.lesson l
          WHERE lv.vocabulary.id = v.id AND l.hidden = true
      )
    ORDER BY vl.nextReviewAt ASC
""")
List<VocabLearningEntity> findDueReviewCards(@Param("userId") Long userId, @Param("now") Instant now);

@Query("""
    SELECT COUNT(vl) FROM VocabLearningEntity vl
    JOIN vl.vocabulary v
    WHERE vl.user.id = :userId
      AND vl.nextReviewAt <= :now
      AND NOT EXISTS (
          SELECT 1 FROM LessonVocabularyEntity lv
          JOIN lv.lesson l
          WHERE lv.vocabulary.id = v.id AND l.hidden = true
      )
""")
long countDueReviewCards(@Param("userId") Long userId, @Param("now") Instant now);
```

#### D. API Contracts
- `GET /api/v1/srs/due-cards`: Lấy danh sách thẻ từ đến hạn hôm nay.
  - Response: `List<SrsCardResponse>` (gồm vocabularyId, word, pinyin, meaning, audioUrl, intervalDays, repetitionLevel).
- `GET /api/v1/srs/summary`: Lấy số lượng từ đến hạn, số từ đã thuộc vững, ngày ôn kế tiếp.
  - Response: `SrsSummaryResponse` (dueTodayCount, masteredCount, learningCount).
- `POST /api/v1/srs/review`: Gửi kết quả lật thẻ cho 1 từ.
  - Request: `SrsReviewRequest(Long vocabularyId, FlashcardResult result)`
  - Response: `SrsReviewResultResponse(Long vocabularyId, int intervalDays, int repetitionLevel, Instant nextReviewAt)`
