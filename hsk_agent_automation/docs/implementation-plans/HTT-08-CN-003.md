### 1. BỐI CẢNH & MỤC TIÊU NGHIỆP VỤ

User Story **HTT-08-CN-003** tạo động lực cho học sinh thông qua hệ thống **Thử thách hằng ngày (Daily Challenge)**. Mỗi ngày, hệ thống đặt ra 3 mục tiêu vi mô để giữ nhịp học tập:
1. **Học bài học:** Hoàn thành các bài học mới (Mục tiêu mặc định: 2 bài).
2. **Ôn từ vựng:** Ôn thẻ từ vựng theo SRS hoặc Flashcard (Mục tiêu mặc định: 10 từ).
3. **Làm bài tập:** Hoàn thành bài tập được giao hoặc bài tập luyện tập (Mục tiêu mặc định: 1 bài tập).

Khi hoàn thành đủ 3 mục tiêu trong ngày (theo múi giờ Việt Nam UTC+7), học sinh được nhận thưởng **+50 XP** kinh nghiệm học tập và ghi nhận duy trì chuỗi học.

#### Các Acceptance Criteria & Test Cases:
- **TC-01 (Hiển thị mục tiêu và tiến độ):** Hiển thị rõ danh sách 3 mục tiêu, tiến độ hiện tại/mục tiêu (ví dụ: `0/2 bài`, `0/10 từ`, `0/1 bài tập`) và phần thưởng XP.
- **TC-02 (Cập nhật tiến độ tự động):** Khi hoàn thành bài học, ôn từ hoặc nộp bài tập, tiến độ của mục tiêu tương ứng được cập nhật tăng.
- **TC-03 (Hoàn thành thử thách ngày):** Khi đạt đủ cả 3 mục tiêu, thử thách được đánh dấu hoàn thành và học sinh nhận thưởng 50 XP.
- **TC-04 (Chống nhận thưởng trùng lặp):** Khi đã hoàn thành thử thách hôm nay, nếu học sinh tiếp tục học thêm thì XP thưởng của thử thách ngày không được cộng thêm lần hai.
- **TC-05 (Chống tính trùng bài học):** Hoàn thành lại một bài đã học xong trong ngày thì không tính tăng thêm vào mục tiêu bài học (dùng `distinct lesson_id`).
- **TC-06 & TC-07 (Múi giờ Việt Nam UTC+7):** Ranh giới ngày tính theo `Asia/Ho_Chi_Minh`. Qua 00:00 ngày mới, thử thách ngày mới bắt đầu với tiến độ về 0.

### 2. THIẾT KẾ CƠ SỞ DỮ LIỆU & KIẾN TRÚC BACKEND

1. **Rà soát Database & Thiết kế Bảng:**
   - Cần lưu lại nhật ký hoàn thành thử thách ngày và điểm thưởng XP của từng học sinh theo ngày để đảm bảo tính Idempotency (chống cộng trùng XP theo TC-04):
   - Tạo bảng `daily_challenge_history`:
     ```sql
     CREATE TABLE IF NOT EXISTS daily_challenge_history (
         id BIGSERIAL PRIMARY KEY,
         user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
         challenge_date DATE NOT NULL,
         completed BOOLEAN NOT NULL DEFAULT FALSE,
         reward_xp INT NOT NULL DEFAULT 50,
         reward_claimed BOOLEAN NOT NULL DEFAULT FALSE,
         completed_at TIMESTAMP WITH TIME ZONE,
         created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
         CONSTRAINT uq_user_challenge_date UNIQUE (user_id, challenge_date)
     );
     CREATE INDEX IF NOT EXISTS idx_daily_challenge_user_date ON daily_challenge_history(user_id, challenge_date);
     ```
   - Thêm cột `total_xp` (mặc định 0) trong `users` nếu chưa có, hoặc cập nhật qua bảng điểm kinh nghiệm.
2. **DTO & API REST Contracts:**
   - `GET /api/v1/gamification/daily-challenge`: Lấy trạng thái thử thách ngày hôm nay:
     ```json
     {
       "date": "2026-10-22",
       "targetLessons": 2,
       "completedLessons": 1,
       "targetVocabs": 10,
       "reviewedVocabs": 10,
       "targetExercises": 1,
       "completedExercises": 0,
       "isCompleted": false,
       "rewardXp": 50,
       "rewardClaimed": false,
       "overallProgressPercent": 66
     }
     ```
   - `POST /api/v1/gamification/daily-challenge/claim-reward`: Nhận thưởng XP khi đủ điều kiện (Idempotent).
3. **Truy vấn tối ưu (Zero N+1):**
   - Đếm số bài học hoàn thành trong ngày: Query `LessonProgressEntity` với `completed = true`, `distinct lesson_id`, trong khoảng thời gian `[startOfDayVn, endOfDayVn]`.
   - Đếm số từ ôn trong ngày: Query `VocabLearningEntity` với `updatedAt` trong `[startOfDayVn, endOfDayVn]`.
   - Đếm số bài tập hoàn thành: Query `AssignmentSubmissionEntity` có trạng thái `SUBMITTED`/`GRADED` trong ngày.

### 3. THIẾT KẾ GIAO DIỆN NGƯỜI DÙNG (UI/UX CONSTRAINTS)

- **TUYỆT ĐỐI KHÔNG DÙNG MODAL/POPUP:** Sử dụng Thẻ Widget "Thử thách hằng ngày" mở rộng tại chỗ (Inline Expand / Dashboard Card) ngay trên `MainWorkspace.tsx`.
- **100% VECTOR SVG ICONS:** Dùng `Trophy`, `Flame`, `BookOpen`, `Sparkles`, `CheckCircle2`, `Target`, `Award`.
- **Gamified Interactive Widget:**
  - 3 thanh tiến độ mini cho 3 nhiệm vụ:
    - 📖 Bài học: `x / 2 bài` (progress bar xanh dương)
    - 🔤 Từ vựng SRS: `y / 10 từ` (progress bar xanh ngọc)
    - 📝 Bài tập: `z / 1 bài tập` (progress bar tím)
  - Badge trạng thái `+50 XP`.
  - Hiệu ứng chúc mừng hoàn thành khi đạt 100%.
