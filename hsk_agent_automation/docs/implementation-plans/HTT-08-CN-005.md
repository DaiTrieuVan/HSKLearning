### 1. BỐI CẢNH & MỤC TIÊU NGHIỆP VỤ

User Story **HTT-08-CN-005** xây dựng cơ chế **Tích lũy Điểm kinh nghiệm (XP) & Hệ thống Cấp bậc (Level Progression)**:
- Học sinh nhận XP cho các hoạt động học tập (Hoàn thành bài học, Ôn từ vựng, Nộp bài tập, Thử thách hằng ngày).
- Tự động nâng Cấp bậc (Level) khi tổng XP chạm ngưỡng của cấp kế tiếp (ví dụ: đạt 100 XP lên Cấp 2).
- **Chống cộng trùng (Idempotent):** Hoạt động đã nhận XP không được cộng lần hai (ví dụ: học lại cùng một bài học không nhận thêm XP).
- **Nhật ký minh bạch (Audit Trail):** Lưu vết nguồn hoạt động, số XP nhận và thời điểm nhận.

#### Acceptance Criteria & Test Cases (TC-01 đến TC-05):
- **TC-01 (Hoàn thành bài học):** Học sinh hoàn thành bài học -> Nhận +10 XP.
- **TC-02 (Các hoạt động khác):** Nộp bài tập (+20 XP), Hoàn thành thử thách ngày (+50 XP), Ôn từ vựng.
- **TC-03 (Lên cấp khi đạt ngưỡng):** Đủ 100 XP -> Lên Cấp 2 và thông báo chúc mừng thăng cấp.
- **TC-04 (Chống lặp - Idempotent):** Hoàn thành lại cùng một bài học đã tính XP -> Không cộng XP lần hai.
- **TC-05 (Lưu lịch sử):** Mọi lần nhận XP đều được ghi nhật ký với nguồn hoạt động, số điểm và thời điểm.

### 2. THIẾT KẾ CƠ SỞ DỮ LIỆU & KIẾN TRÚC BACKEND

#### A. Database Schema (Flyway Migration `V18__create_user_xp_transactions_table.sql`):
```sql
CREATE TABLE IF NOT EXISTS user_xp_transactions (
    id BIGSERIAL PRIMARY KEY,
    user_id BIGINT NOT NULL REFERENCES users(id) ON DELETE CASCADE,
    xp_amount INT NOT NULL,
    source_type VARCHAR(50) NOT NULL,
    source_id VARCHAR(100),
    description VARCHAR(255) NOT NULL,
    created_at TIMESTAMP WITH TIME ZONE NOT NULL DEFAULT NOW(),
    CONSTRAINT uq_user_xp_source UNIQUE (user_id, source_type, source_id)
);

CREATE INDEX IF NOT EXISTS idx_user_xp_user_id ON user_xp_transactions(user_id);
CREATE INDEX IF NOT EXISTS idx_user_xp_created_at ON user_xp_transactions(created_at DESC);
```

#### B. Quy tắc tính Cấp bậc (Level Formula):
Thiết kế bảng cấp bậc chuẩn hóa:
- **Cấp 1 (Tân thủ - Beginner):** 0 – 99 XP
- **Cấp 2 (Tập sự - Novice):** 100 – 249 XP (Ngưỡng lên cấp: 100 XP theo TC-03)
- **Cấp 3 (Chăm chỉ - Dedicated):** 250 – 449 XP
- **Cấp 4 (Tiến bộ - Skilled):** 450 – 699 XP
- **Cấp 5 (Thành thạo - Master):** 700 – 999 XP
- **Cấp 6 (Tinh hoa - Elite):** 1000 – 1499 XP
- **Cấp 7 (Bậc thầy - Grandmaster):** 1500+ XP

Tính toán % tiến độ đến cấp kế tiếp:
$$\text{progressPercent} = \min\left(100, \frac{\text{totalXp} - \text{currentMinXp}}{\text{nextMinXp} - \text{currentMinXp}} \times 100\right)$$

#### C. Bảng phân phối điểm XP:
- `LESSON_COMPLETION`: `+10 XP` (mỗi `lessonId` nhận 1 lần)
- `ASSIGNMENT_SUBMISSION`: `+20 XP` (mỗi `assignmentId` nhận 1 lần)
- `DAILY_CHALLENGE`: `+50 XP` (mỗi ngày nhận 1 lần)
- `VOCAB_REVIEW`: `+1 XP` mỗi từ

#### D. REST API Contracts:
1. `GET /api/v1/gamification/level`:
   ```json
   {
     "currentLevel": 2,
     "title": "Tập sự",
     "totalXp": 120,
     "currentLevelThreshold": 100,
     "nextLevelThreshold": 250,
     "xpToNextLevel": 130,
     "progressPercent": 13
   }
   ```
2. `GET /api/v1/gamification/xp-history?page=0&size=10`:
   Danh sách phân trang các giao dịch nhận điểm XP.
